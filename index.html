COMMON INQUIRIES

자주 묻는 질문

HYPERFPS는 진짜 프레임을 올려주나요?

백그라운드 리소스 확보, 프로세스 우선순위 상향, 메모리 정리를 통해 프레임 드랍을 줄이고 평균 FPS를 높입니다. 하드웨어를 바꾸는 것은 아니며, 시스템 상태에 따라 체감이 다를 수 있습니다.

바이러스/Windows 경고가 떠요. 안전한가요?

백신이 "오탐(false positive)"으로 이 프로그램을 경고하는 경우가 흔합니다. 이유는 PyInstaller 패키징 방식과 자체 서명(공인 인증서 미보유) 때문입니다. 실제 파일이 맞는지 확인하려면 사이트의 SHA-256 값과 위 파일이 일치하는지 대조해 주세요. Windows SmartScreen 경고는 "추가 정보 → 그래도 실행" 을 선택하면 진행됩니다.

PRO를 구매하면 어떻게 받나요?

구매를 완료하면 관리자가 온라인 키를 발급해 드립니다. 앱의 LICENSE 탭에 키를 입력하면 PRO가 즉시 활성화됩니다. 키는 1회 구매로 평생 유효합니다.

핑 최적화는 어떻게 동작하나요?

TCP 오토튜닝·ECN·타임스탬프 설정, DNS 캐시 플러시, 네트워크 스로틀 해제, 시스템 응답 우선순위 조정으로 지연을 줄입니다. 인터넷 속도 자체를 높이는 것은 아닙니다.

관리자 권한이 필요한가요?

네. 프로세스 우선순위와 네트워크 최적화는 관리자 권한이 필요합니다. 앱 실행 시 자동으로 권한 상승을 요청합니다.

환불이 가능한가요?

디지털 키 특성상 환불은 불가합니다. 무료 버전을 먼저 사용해 보시고 구매를 결정하세요.
